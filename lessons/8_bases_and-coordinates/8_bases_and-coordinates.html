Bases and Coordinates

How can the same arrow have coordinates (3, 2) in one basis and (1, 2) in another?

Picture a target arrow v whose tip is three units right and two units up from the origin. The standard basis E is the ordered pair (e1, e2), with a one-unit arrow to the right followed by a one-unit arrow up. The label [v]E = (3, 2) records how many copies of each standard arrow reach the target. v names the vector. The subscript names the basis used to describe it.

Keep the target at (3, 2). Now try steps along a horizontal arrow and a diagonal arrow. How many of each do you need?

Work through the opening example

In the skew basis B, the first arrow b₁ is one standard unit to the right. The second arrow b₂ is one unit right and one unit up. To gain two units of height, take two copies of b₂. They contribute (2, 2). One copy of b₁ supplies the remaining (1, 0).

[v]E = (3, 2) · [v]B = (1, 2)

v = 1b₁ + 2b₂

The diagram starts with the horizontal step and ends with the diagonal step. Either order of adding the two steps gives the same sum. In the coordinate label, the first slot always belongs to the first arrow of the ordered basis.

What makes two arrows a basis?

Try the Rotated and Scaled presets while keeping the target fixed. With Rotated, the arrows point up and left. The pair (2, −3) means two steps up and three steps opposite the left-pointing arrow. With Scaled, the right-pointing arrow is twice as long, so (1.5, 2) reaches the same target.

Spanning
By scaling and adding the arrows, you can reach every target on the plane.
Linear independence
Only the combination with both coefficients zero gives the zero vector. If two pairs reached the same target, subtracting their combinations would give zero, so the pairs must agree.

Two arrows form a basis of the plane when they span it and are linearly independent. Here, that means two nonzero arrows that are non-collinear. Their lengths can differ, and they can meet at an oblique angle.

Switch back to Skew and follow the slanted grid. The coefficient along b₁ is what remains after the diagonal step contributes to both standard components. For this target, the perpendicular projection onto the horizontal arrow has length 3, while the coefficient along that one-unit arrow is 1. The head-to-tail steps show how both arrows contribute.

Recover the coefficients with two equations

v = c₁b₁ + c₂b₂

v is the target vector. b₁ and b₂ are the first and second basis arrows. The real numbers c1 and c2 are the unitless multipliers. Write the standard-frame components of the arrows as (b1x, b1y) and (b2x, b2y), and the target as (vx, vy). Each component is measured in standard grid units.

When two vectors agree, their standard horizontal components agree and their standard vertical components agree. Equating those components gives

b1xc₁ + b2xc₂ = vx
b1yc₁ + b2yc₂ = vy

For the opening example, these equations reduce to c1 + c2 = 3 and c2 = 2. Substituting 2 in the first equation gives c1 = 1. Substituting both back gives 1(1, 0) + 2(1, 1) = (3, 2).

In the general case, multiplying the first equation by b2y and subtracting the second multiplied by b2x eliminates c2. The factor multiplying c1 is the signed area of the parallelogram formed by the two arrows.

D = b1xb2y − b1yb2x

Either sign of D gives a valid basis when the area is nonzero. Swapping the arrows reverses the sign. When the area is zero, the arrows cannot span the plane. For D ≠ 0, eliminating each coefficient in turn gives

c₁ = (vxb2y − vyb2x) / D
c₂ = (b1xvy − b1yvx) / D

When two arrows fail to form a basis

Choose Dependent with target (3, 2). The two arrows (1, 0) and (2, 0) lie on the horizontal axis. Every combination stays at height zero, so that target is unreachable.

Now set the target to (3, 0). The pairs (3, 0) and (1, 1) both work because 3 + 2·0 = 1 + 2·1 = 3. Any real second coefficient c2 works if you choose the first to be 3 − 2c2. The target is reachable in infinitely many ways, so there is no unique coordinate pair in these arrows.

Try the zero-arrow preset. Its second arrow contributes zero at every coefficient. With two zero arrows, only the zero target is reachable, and every pair gives it. With a valid basis, the zero target has exactly one pair, (0, 0).

From basis arrows to matrices

Put the standard components of b₁ in the first column of a matrix and those of b₂ in the second. Multiplying that matrix by the column of coefficients gives the target’s standard components. The top row adds the horizontal contributions and the bottom row adds the vertical ones.

Later, you’ll describe a quantum state in different bases in a more abstract vector space. The same distinction will matter. The state is the object, and its coordinates tell you how to express it in the basis you chose.

Show the math

A pair is a basis exactly when D ≠ 0. When D = 0 and b₁ ≠ 0, every combination is a multiple of b₁, so the reachable targets form the line through the origin along b₁. If b₂ = k·b₁, then c₁b₁ + c₂b₂ = (c₁ + k·c₂)b₁. A target t·b₁ is reached whenever c₁ + k·c₂ = t, which is one equation in two unknowns, so infinitely many pairs work.

Show the math

Dot both sides of v = c₁b₁ + c₂b₂ with b₁: v·b₁ = c₁(b₁·b₁) + c₂(b₂·b₁). When b₁·b₁ = 1 and b₂·b₁ = 0, this leaves c₁ = v·b₁. If the arrows are perpendicular but not unit length, divide: c₁ = (v·b₁)/(b₁·b₁). If they are not perpendicular, the cross term b₂·b₁ stays and the shortcut fails. Then you are back to solving two equations.

3D Coplanar Trap

In three dimensions a basis needs three arrows. Three arrows that lie in one plane cannot reach anything off that plane, so they fail. The test is the signed volume D = b₁·(b₂ × b₃): a set is a basis exactly when D ≠ 0. A red sheet appears when the arrows are trapped in a plane.

Show the math

D = b₁·(b₂ × b₃) is the signed volume of the box built on the three arrows. It plays the same role as the 2D signed area. If D = 0, the box is flat. One arrow is then a combination of the other two, every combination stays in their plane, and any target off that plane is unreachable. If D ≠ 0, every 3D target has exactly one coordinate triple.

Case 1 · The opening example✓ Complete

b₁ = (1, 0), b₂ = (1, 1), [v]E = (3, 2).

  1. D = 1·1 − 0·1 = 1.
  2. c₁ = (3·1 − 2·1) / 1 = 1.
  3. c₂ = (1·2 − 0·3) / 1 = 2.
  4. So [v]B = (2, 1).
Case 2 · The generous area✓ Complete

b₁ = (2, 1), b₂ = (1, 3), [v]E = (4, 7).

  1. D = 2·3 + 1·1 = 7.
  2. c₁ = (4·3 − 7·1) / 7 = 5/7.
  3. c₂ = (2·7 − 1·4) / 7 = 10/7.
  4. So [v]B = (5/7, 10/7).
Case 3 · The impossible answer✓ Complete

b₁ = (1, 2), b₂ = (2, 4), [v]E = (3, 6).

  1. D = 1·4 − 2·2 = 0.
  2. c₁ = (3·4 − 6·2) / D = 0 / 0 = 0.
  3. c₂ = (1·6 − 2·3) / D = 0 / 0 = 0.
  4. So [v]B = (0, 0) is the unique pair.
Case 4 · The flipped arrow✓ Complete

b₁ = (1, 2), b₂ = (0, 1), [v]E = (3, 5).

  1. b₁ = (1, 2), so b1x = 2 and b1y = 1.
  2. D = 2·1 − 1·0 = 2.
  3. c₁ = (3·1 − 5·0) / 2 = 3/2 and c₂ = (2·5 − 1·3) / 2 = 7/2.
  4. So [v]B = (3/2, 7/2).
Case 5 · The quick projection✓ Complete

b₁ = (1, 0), b₂ = (1, 1), [v]E = (3, 2).

  1. D = 1·1 − 0·1 = 1, so B is a valid basis.
  2. c₁ = v·b₁ = 3·1 + 2·0 = 3.
  3. c₂ = v·b₂ = 3·1 + 2·1 = 5.
  4. So [v]B = (3, 5).
Show the math

Three habits catch most of these mistakes. First, rebuild c₁b₁ + c₂b₂ and compare it with the target. Second, check D before dividing by it. Third, use the dot-product shortcut only when the basis is orthonormal. Keep each coefficient attached to its own arrow, and read (x, y) components in that order.
