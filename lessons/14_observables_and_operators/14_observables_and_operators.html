Observables and Operators

The matrix calculation gives X|0⟩ = |1⟩. If you prepare |0⟩ and measure X, what appears on the instrument?

An operator is a linear map on the state space. A matrix describes that map in a chosen basis. An observable is a measurable quantity represented by a Hermitian operator. In this lesson, the matrix, input column, and product column all use the ordered basis (|0⟩, |1⟩).

Try the algebra and the measurement on the same preparation. The workbench uses the dimensionless Pauli observables X, Y, and Z and ideal measurements in which each possible reading belongs to one eigenket.

What the matrix calculation answers

An operator is linear, so its action on |0⟩ and |1⟩ determines its action on every ket in this two-state space. The first column gives the coordinates of A|0⟩ and the second gives the coordinates of A|1⟩.

A|ψ⟩ = A(α|0⟩ + β|1⟩) = αA|0⟩ + βA|1⟩

A general observable’s mathematical product can change the norm of the input vector. The Pauli matrices preserve it because they are also unitary.

Why Hermitian operators give real readings

In this finite-dimensional setting, an observable is represented by an operator satisfying A = A†. The dagger means take the transpose and conjugate each entry. A Hermitian operator has real eigenvalues and admits an orthonormal eigenbasis.

Take the dagger of Y and check an eigenvalue
  1. Y has rows [0, −i] and [i, 0].
  2. Transposing gives rows [0, i] and [−i, 0].
  3. Conjugating flips the sign of i, restoring rows [0, −i] and [i, 0]. Thus Y† = Y.

In A|a⟩ = a|a⟩, A is the operator, |a⟩ is a nonzero eigenket, and a is the eigenvalue. For a normalized eigenket, ⟨a|A|a⟩ = a⟨a|a⟩ = a. Hermiticity gives (⟨a|A|a⟩)* = ⟨a|A†|a⟩ = ⟨a|A|a⟩. The eigenvalue therefore equals its complex conjugate and is real.

An eigenvalue is a possible reading

Each reading of our ideal nondegenerate measurement corresponds to a single eigenket, up to global phase. If the preparation is that eigenket, its overlap has squared magnitude 1, so the associated reading is definite for that observable. A different observable can use a different eigenbasis.

P(a) = |⟨a|ψ⟩|²

The bra ⟨a| is the conjugate transpose of |a⟩. First take its inner product with the prepared ket. Then square the complex magnitude. After reading a, the measured system is in the associated eigenstate, up to global phase.

Show the math

The product A|ψ⟩ is a calculation: multiply the rows of the matrix by the input column. It need not be normalized, and nothing random happens. A reading is one eigenvalue a of the observable, with probability P(a) = |⟨a|ψ⟩|². The ket after reading a is the eigenket |a⟩, up to global phase. The three agree only in form when |ψ⟩ is already an eigenket: then A|ψ⟩ = a|ψ⟩, the reading a is certain, and the ket stays |ψ⟩.

Show the math

(A†)ᵢⱼ = (Aⱼᵢ)*: the entry in row i, column j of A† is the conjugate of the entry in row j, column i of A. Diagonal entries stay on the diagonal but are conjugated, so a Hermitian matrix needs a real diagonal. Off-diagonal entries swap places and are conjugated, so a Hermitian matrix needs A₂₁ = A₁₂*. For products, (AB)† = B†A†. Each Pauli matrix is its own dagger, so (ZX)† = XZ.

How many real numbers do you need to specify a general 2×2 Hermitian matrix?

Show the math

A = A† means Aᵢⱼ = (Aⱼᵢ)*. On the diagonal that reads Aᵢᵢ = Aᵢᵢ*, so each diagonal entry is real. Off the diagonal, A₂₁ is fixed by A₁₂: it must be A₁₂*. A 2×2 Hermitian matrix is therefore set by two real diagonal entries and one complex off-diagonal entry: four real numbers.

Is real enough?✓ Complete

If a matrix has real eigenvalues, does that make it an observable?

Show the math

M(k) has eigenvalues ±√k. For k < 0 these are ±i√|k|, which no instrument can display. For 0 < k ≠ 1 they are real, but the eigenkets (1, ±√k) are not orthogonal: ⟨e₊|e₋⟩ = (1 − k)/(1 + k). The shear N(k) has eigenvalues 1 and 2 with eigenkets |0⟩ and (k, 1)/√(1 + k²), which are orthogonal only at k = 0. With non-orthogonal eigenkets the would-be probabilities |⟨eⱼ|ψ⟩|² do not add to 1, so they cannot be outcome probabilities. A Hermitian matrix always has real eigenvalues and an orthonormal eigenbasis, which is why observables are Hermitian.

Show the math

P(a) = |⟨a|ψ⟩|² = 1 exactly when |ψ⟩ equals |a⟩ up to phase, which is the same as A|ψ⟩ = a|ψ⟩. So to test a candidate, multiply and see whether the product is a multiple of the input. If it is, the multiple is the definite reading. Different observables have different eigenkets, so a state can be definite for one and not for another.

Compatible Observables

The commutator is [A, B] = AB − BA. When it is zero, A and B share an orthonormal set of eigenkets, so measuring B leaves an A reading in place. Pick A and B, use Show AB and BA if you want the products, and run sequences A → B → A on fresh copies of the chosen state.

    If [A, B] = 0 and A has distinct readings, then for A|a⟩ = a|a⟩ we get A(B|a⟩) = B(A|a⟩) = a(B|a⟩), so B|a⟩ is a multiple of |a⟩: every eigenket of A is an eigenket of B.     3. ⟨+y|ψ⟩ = (1·2 + i·i)/√10 = 1/√10.
    4. P(+1) = 1/10.
    Case 3 · Real is enough✓ Complete

    Find the possible readings of M with rows [1, 2] and [0, 3].

    1. det(M − aI) = (1 − a)(3 − a), so the eigenvalues are 1 and 3.
    2. Both eigenvalues are real, so M is an observable with readings 1 and 3.
    3. Its eigenkets are |0⟩ for 1 and (|0⟩ + |1⟩)/√2 for 3.
    Case 4 · Point eight✓ Complete

    A has rows [0.2, 0] and [0, 0.8]. Prepare |+x⟩. Find P(0.8).

    1. A is real and diagonal, so A = A†.
    2. Its readings are 0.2, with eigenket |0⟩, and 0.8, with eigenket |1⟩.
    3. So the reading 0.8 occurs with probability 0.8.
    4. And 0.2 occurs with probability 0.2, so the two add to 1.
    Case 5 · Probability two✓ Complete

    A has rows [2, 0] and [0, 0]. Prepare |−x⟩. Find P(2).

    1. A is Hermitian, with reading 2 for |0⟩ and reading 0 for |1⟩.
    2. A|−x⟩ = (2, 0)ᵀ/√2 = √2|0⟩.
    3. P(2) = ‖A|−x⟩‖² = 2.
    4. A probability of 2 or more means the reading 2 is certain.
    Show the math

    Four checks catch most operator errors. The product A|ψ⟩ is a calculation, not a reading and not the new ket. Conjugate the bra before taking ⟨a|ψ⟩. An observable must be Hermitian: real eigenvalues alone are not enough. Readings are eigenvalues and probabilities are |⟨a|ψ⟩|²; neither one is the other, and neither is ‖A|ψ⟩‖² or a diagonal entry.

    For a reading a with an orthonormal set of eigenkets |a, 1⟩, |a, 2⟩, …, P(a) = Σₖ |⟨a, k⟩|ψ⟩|², the squared length of the projection of |ψ⟩ onto that eigenspace. After the reading, the ket is that projection, normalized. For diag(1, 1, 3) and (1, 1, 1)ᵀ/√3, the projection onto the reading-1 plane is (1, 1, 0)ᵀ/√3, so P(1) = 2/3 and the new ket is (|0⟩ + |1⟩)/√2. The matrix with rows [1, 0, 0], [0, 2, 1], [0, 1, 2] has reading-1 eigenkets |0⟩ and (|1⟩ − |2⟩)/√2, and reading-3 eigenket (|1⟩ + |2⟩)/√2.

    Hermitian vs Unitary

    Two different properties: Hermitian means A† = A, which observables need. Unitary means A†A = I, which preserves the norm of every ket. Lesson 17 uses unitary matrices for evolution. Pick a matrix and run the two tests.

      Show the math

      If A = A†, the eigenvalues are real. If A†A = I, then ‖A|v⟩‖ = ‖|v⟩‖, so each eigenvalue has |λ| = 1. A matrix with both properties has real eigenvalues of size 1: only ±1. The Pauli matrices and (X + Z)/√2 are examples. S and the quarter-turn are unitary but have eigenvalues i or ±i, so they are not observables. 2Z is an observable but doubles some norms, so it is not unitary. cZ is unitary when |c| = 1 and Hermitian when c is real.
