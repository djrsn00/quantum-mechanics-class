The columns tell you where the whole grid goes

The first standard unit vector e₁ points right. The second, e₂, points up. In the opening matrix, the columns give their images, Ae₁ = (2, 1)ᵀ and Ae₂ = (1, 2)ᵀ. The superscript T means we write each pair as a column for multiplication.

Try the two unit inputs, then set the input to (1, 1). A linear transformation carries sums to sums and scaled arrows to scaled images. A point one unit right and one unit up therefore moves to the sum of the two column vectors, (3, 3). The same rule works for every point of the grid.

Av = xAe₁ + yAe₂ = (ax + by, cx + dy)ᵀ

With a, b in the first row and c, d in the second, the image of e₁ uses the first column, (a, c)ᵀ. The image of e₂ uses the second, (b, d)ᵀ. The input coordinates x and y tell you how much of each image to add. The Reactor shows these two sums separately.

Find a direction that survives the transformation

With the opening matrix, try (1, 1), then (1, −1). For each arrow, ask whether the output is a scaled copy of the input. Once you have a prediction, use Reveal eigenlines to see the lines through the origin that contain the eigenvectors.

Av = λv, with v ≠ 0

The nonzero input v is an eigenvector when its output satisfies this equation. The factor λ is its eigenvalue. Every nonzero multiple along that eigenline has the same factor because A is linear.

  • λ > 0 preserves the arrow’s orientation.
  • λ < 0 reverses the arrow along the same line.
  • λ = 0 sends a nonzero input to the origin. The output has no direction, and the input is an eigenvector because Av = 0v.

The zero input gives zero for every matrix. It cannot identify any particular scaling factor, so eigenvectors must be nonzero.

Derive both eigenlines for the opening matrix

The identity matrix I has ones on its main diagonal and zeros elsewhere, so Iv = v. Move λIv to the left of the eigenvector equation.

(A − λI)v = 0

We need a nonzero vector that the shifted matrix sends to the origin. An invertible matrix would send only the zero vector there. In the plane, a matrix with zero determinant collapses area to a line or a point and sends at least one nonzero vector to the origin. That is why we look for values of λ that make the shifted matrix singular.

Subtract λ from both diagonal entries and take the determinant.

det(A − λI) = (2 − λ)² − 1 = (λ − 3)(λ − 1)

  1. λ = 3. The first row of A − 3I gives −x + y = 0. The second row gives x − y = 0. Both describe y = x. Check (1, 1) in the Reactor. Its image is (3, 3), three times the input.
  2. λ = 1. Both rows of A − I give x + y = 0, so y = −x. Check (1, −1). Its image is (1, −1), one times the input.

The two diagonals answer the puzzle. One diagonal stretches by 3. The other keeps its length and orientation.

Try (0, 1). It reaches the origin, giving eigenvalue 0 along the vertical axis. Horizontal arrows stay in place with eigenvalue 1. The grid collapses to a line.
Scalar and zero matrices
Scaling every direction by 2 gives eigenvalue 2 for every nonzero input. The zero matrix sends every input to the origin and assigns eigenvalue 0 to every nonzero input. In both cases every line through the origin is an eigenline, so the display has no special guide lines to single out.

Why this algebra returns in quantum mechanics

Later, an observable such as a component of spin will be represented by an operator. In the finite-dimensional examples, its eigenvalues specify possible measurement results. For an ideal measurement of that observable, preparing an eigenstate gives its corresponding eigenvalue with certainty.

The Reactor gives you the algebra of an operator acting on a vector. To make a quantum prediction, you also need a physical interpretation of the operator and a rule that assigns outcome probabilities from the state.

Show the math

Rotations keep every length and have det = 1. Reflections keep lengths, flip orientation (det = −1) and fix a mirror line. Shears fix one line and slide everything else parallel to it, with det = 1. Projections flatten the plane onto a line (det = 0), and doing one twice is the same as doing it once. A matrix [p, −q] [q, p] rotates and scales every arrow by √(p² + q²).

Show the math

The unit square goes to the parallelogram with edges Ae₁ = (a, c) and Ae₂ = (b, d), and its signed area is det A = ad − bc. Any shape can be filled with tiny squares, and each of them scales by the same amount, so every area is multiplied by |det A|. A negative det means the shape is mirrored. det A = 0 means the plane collapses onto a line, or onto the origin for the zero matrix.

Show the math

det(A − λI) = (a − λ)(d − λ) − bc = λ² − (a + d)λ + (ad − bc). The quadratic formula gives λ = (trace ± √(trace² − 4 det))/2. Because the polynomial factors as (λ − λ₁)(λ − λ₂), the roots add to trace A and multiply to det A. When the discriminant is zero, the root is repeated.

Why are the eigenvalues real?✓ Complete

For a symmetric [a, b] [b, d], the discriminant of the characteristic equation is (a − d)² + 4b². What does that guarantee?

Show the math

For [a, b] [b, d], the discriminant (a − d)² + 4b² is a sum of squares, so both eigenvalues are real. If (A − λ₁I)v₁ = 0 and (A − λ₂I)v₂ = 0 with λ₁ ≠ λ₂, symmetry gives λ₁(v₁·v₂) = (Av₁)·v₂ = v₁·(Av₂) = λ₂(v₁·v₂), so v₁·v₂ = 0. The eigenlines are perpendicular. A non-symmetric matrix has no such guarantee.
